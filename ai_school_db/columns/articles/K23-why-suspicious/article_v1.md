## AI講座を含むビジネス講座の相談は5年で約3倍
AI講座やSNS運用講座など、仕事に役立つ知識や技術を学ぶ講座を、国民生活センターは「ビジネス講座」と呼ぶ。全国の消費生活センターなどに寄せられたその相談は、2025年度に3,551件あった。2020年度の1,169件から約3倍に増えている。この件数はAI講座に限らず、ビジネス講座全体を数えたもの。相談の内容でいちばん多いのは解約で、ほぼ半数を占める。

| 相談の内容（複数回答） | 件数 | 3,551件に占める割合 |
|---|---|---|
| 解約（全般） | 1,748件 | 49.2% |
| 電話勧誘 | 1,655件 | 46.6% |
| SNS | 1,511件 | 42.6% |
| 返金 | 1,193件 | 33.6% |
| 電子広告 | 1,162件 | 32.7% |

※出典：国民生活センター｜ビジネス講座のトラブルにご注意（2026年9月16日公表）。2025年度に受け付け、全国の消費生活相談のデータベース（PIO-NET）に2026年7月31日までに登録された相談。1件に複数の内容が付くため、割合を足すと100%を超える。

相談事例から国民生活センターが挙げた問題には、広告や勧誘で抱いた印象と、受けてみた講座の中身が違うことがある。解約の条件を説明されていない、条件が厳しいといった問題も挙がった。講座は受けてみるまで中身や難しさ、自分に合うかが分かりにくく、広告や勧誘で抱いた印象に判断が左右されやすい。それでも、広告の数字の根拠と、解約・返金の条件は、申し込む前に読めるものが多い。

## 「No.1」の根拠は、注記の調査対象と時期で読む
「No.1」は、誰に何を聞き、どの相手と比べた結果かで意味が大きく変わる。消費者庁は2024年9月に「No.1表示に関する実態調査報告書」を公表した。それによると、2023年度に景品表示法の措置命令を受けた44事業者のうち、13事業者がNo.1表示に関わる事案だった。景品表示法は、商品やサービスの中身や取引の条件を、実際や他社より著しくよく見せる表示を禁じる法律。措置命令は、そうした表示をやめるよう消費者庁が命じる処分を指す。13事業者は、いずれもサイトを見せて印象で選ばせる「イメージ調査」を根拠に、「顧客満足度No.1」などと表示していた。

この表示が見る人に与える影響は小さくない。同じ報告書のアンケート（消費者1,000人）では、No.1表示が購入の判断に「かなり」か「やや」影響すると答えた人が約5割いた。実際の利用者に調べた結果だと受け取る人も、4割を超えた。消費者庁は、こうした表示の根拠として認められるには、比べる相手の選び方、答える人の選び方、調査の方法、表示と結果の対応がそろう必要があるとしている。

> 例（架空の広告）：受講者満足度No.1※
> ※調査機関：○○リサーチ／調査期間：2024年5月／対象：全国の20〜69歳の男女1,000名／方法：「AIスクール」で検索して上位に出た10社のサイトを見てもらい、満足できそうなスクールを1つ選んでもらった

| 注記で読むところ | この例で分かること |
|---|---|
| 答えた人 | 一般の1,000名で、受講した人とは限らない。「受講者満足度」とうたう表示と合わない |
| 調べ方 | サイトを見た印象で選ぶイメージ調査。受講して満足したかは聞いていない |
| 比べた相手 | 検索で上位に出た10社だけ。主なスクールをすべて比べたとは限らない |
| 時期 | 2024年5月。その後に講座の中身や料金、運営会社が変わっていないかを確かめる |

※消費者庁は、イメージ調査だと注記していても、「顧客満足度No.1」という表示と調査の中身は合わないとしている。注記の位置や文字の大きさ、色のせいで読み取りにくい場合も、問題になるおそれがある（消費者庁｜No.1表示に関する実態調査報告書、2024年9月26日公表）。

AI講座でも、根拠の書き方はまちまちだった。編集部は2026年10月10日時点で、AI講座21講座の公式サイトや運営会社の発表を調べた。「No.1」「日本初」「最大級」や、満足度・合格率の高さをうたう表示は、9講座で確かめた。このうち7講座は、調べた機関・時期・方法の記載がないか、一部しか書かれていなかった。記載があった2講座のうち1講座は、調査期間が今の月額制のサービスが始まる前のものだった。

※出典：編集部調べ（2026年10月10日時点）。残る12講座は、表示がなかった1講座と、記録のない11講座で、記録のない講座にも表示がある場合がある。

注記が見当たらない表示や、注記を読んでも答えた人が分からない表示は、選ぶ理由から外す。気になるときは、根拠を問い合わせる（文例は「申し込む前に、広告と規約で確かめること」の章）。根拠のない表示だと考えたら、消費者庁の「景品表示法違反被疑情報提供フォーム」から情報を送れる。

## 転職成功率は、分母に入る人と集計期間を確かめる
転職成功率のような実績の数字は、注記の条件しだいで、数える人を絞れる。消費者庁の考え方では、広告で強く打ち出した内容に例外や条件があるなら、見る人が分かるように示す必要がある。注記の文字が小さいなどで見る人が気付かず、実際よりよいと誤解される場合は、景品表示法の問題になるおそれがある（消費者庁｜打消し表示に関する実態調査報告書（概要）、2017年7月14日公表）。

> 例（架空の広告）：転職成功率97.5%※
> ※2024年10月〜2025年9月に所定のカリキュラムを修了し、当社の転職支援を利用して転職活動をした方のうち、内定を得た方の割合

| 人数（例） | 数える人 | 割合 |
|---|---|---|
| 100人 | 受講を始めた人 | — |
| 60人 | そのうち修了した人 | 受講者の60% |
| 40人 | そのうち転職支援を使って転職活動をした人 | 受講者の40% |
| 39人 | そのうち内定を得た人 | 40人のうち97.5%、受講者全体では39% |

※人数はすべて架空。注記の条件に合う40人が分母になり、途中でやめた人や、自分で転職活動をした人は数に入らない。

注記を読むときは、分母に入る人のほかに、集計した期間と、何を「成功」と数えたかを確かめる。期間が何年も前なら、講座の中身や運営会社が今と同じかを見る。「成功」が内定なのか、学んだ分野の仕事への転職なのかでも意味が変わる。公式サイトの受講者の声も、運営会社が選んで載せたもの。消費者庁の同じ調査では、体験談に「個人の感想です」と添えても、多くの人が効果を得られるという印象はほとんど変わらないとされた。

編集部が調べたAI講座21講座でも、実績の数字の注記には差があった。転職成功率を載せていた1講座は、注記に対象（所定の学習と転職活動をした人）と集計期間を書いていた。ただ、その期間は2022年3月から2023年9月までで、講座の運営会社が変わる前にあたる。

| 公式サイトなどで確かめたこと | AI講座21講座での数 |
|---|---|
| 合格率・修了率・転職成功率などの実績の数字 | 6講座 |
| 　うち、集計の時期や対象・方法の注記がない | 2講座 |
| 転職・就職の支援（相談・求人紹介など。一部のプランだけを含む） | 7講座 |
| 　うち、転職成功率を載せている | 1講座 |

※出典：編集部調べ（2026年10月10日時点）。AI講座21講座の公式サイト、運営会社の発表、利用規約を確かめた。実績の数字の記録がない講座にも、数字を載せている場合がある。

## 返金と解約の条件は、申し込む前に規約で読む
AI講座の返金の条件は、講座によって大きく違う。編集部が21講座の利用規約などを調べたところ、8講座は、払った後は自己都合なら受講を始める前でも受講料を返さないと定めていた。条件を満たせば返金する講座も、その条件は契約から8日以内、受講を始める前、本人の重い病気などさまざまだった。

| 利用規約などで分かったこと | AI講座21講座での数 |
|---|---|
| 払った後は、自己都合なら受講を始める前でも受講料を返さない | 8講座 |
| 条件を満たせば返金する（契約から8日以内、受講を始める前、本人の死亡や重い病気など。条件は講座ごとに違う） | 9講座 |
| 公式サイトや規約から返金の条件を読み取れなかった（無料相談で案内するとしている講座を含む） | 4講座 |
| 契約から8日以内の解約・返金を規約などに定めている | 4講座 |
| 途中でやめたとき、残りの分を精算する | 2講座 |
| 期間が終わると自動で更新される | 5講座 |

※出典：編集部調べ（2026年10月10日時点）。AI講座21講座の公式サイト、利用規約、特定商取引法に基づく表記（事業者の名前・連絡先や返品・解約の条件を載せるページ）を確かめた。

規約を開いたら、返金の期限の数え方と「受講開始」の意味から読む。

1. **全額返金の期限**：「契約から8日以内」などの期限が、何を受け取った日から数えるのかを確かめる。
2. **受講開始の意味**：「受講開始後は返金しない」とあるなら、開始がアカウントの発行か、初回のログインか、初回のレッスンかを確かめる。申し込んですぐに開始扱いになる講座もある。
3. **途中でやめたときの精算の式**：受講した分の料金、解約手数料、入学金が戻るかを確かめ、自分の受講料で計算する。
4. **自動更新の締め切り**：月額や期間ごとの契約なら、次の期間に進まないための退会の期限を確かめる。

たとえば受講料30万円（入学金なし）、全12回のレッスンのうち3回を受けてやめるとする。規約に「受講済みの回数分の料金と、解約手数料（5万円か、まだ受けていない分の20%の低いほう）を差し引いて返す」とあれば、戻るのは18万円になる。

| 項目 | 計算 | 金額 |
|---|---|---|
| 受講済みの3回分 | 30万円×3÷12 | 7万5,000円 |
| まだ受けていない分 | 30万円−7万5,000円 | 22万5,000円 |
| 解約手数料 | 22万5,000円×20%＝4万5,000円（5万円より低い） | 4万5,000円 |
| 戻る額 | 30万円−7万5,000円−4万5,000円 | 18万円 |

※条件はすべて架空の例。入学金が戻らないと定める講座もあり、その場合は入学金の分だけ戻る額が減る。

さらに詳しく：「契約後すぐの解約は受け付けていない」と言われたら　AIスクールのクーリング・オフと中途解約のルール（自分の契約に8日間のクーリング・オフがあるか、途中でやめるときに規約のどこを読むかが分かる）

## 独学で足りる場面、質問相手と期限が要るならスクール
生成AIをメールや報告書の下書き、要約、調べものに使うなら、まず独学で試せる。総務省がサイトで公開している「生成AIはじめの一歩」は、初心者向けに生成AIの使い方と注意点を紹介する教材で、各社の公式ヘルプとあわせて基本を確かめられる。つまずいたときに聞ける相手や、学ぶ期限がほしいときには、スクールが役に立つ。

| いまの状況 | 向く学び方 | 手がかり |
|---|---|---|
| 文章の下書きや要約、調べものに生成AIを使いたい | 独学から始める | 総務省の公開教材、各社の公式ヘルプ、勤務先の利用ルール |
| 教材は読めるが、エラーや使い方で止まったときに聞ける人がいない | 質問できる講座 | 講師やスタッフが質問に答える講座は、21講座中16講座 |
| ひとりでは続かず、期限を決めて身につけたい | レッスンの日程が決まる講座 | 週1回のレッスン、期ごとの開講など |
| E資格（ディープラーニングを実装する技術者向けの資格）を受けたい | 認定された講座の修了が必要 | 日本ディープラーニング協会（JDLA）の認定プログラムを、試験日の前2年以内に修了した人が受験できる |
| 受講料の一部を国の制度で戻したい | 制度の対象講座 | 教育訓練給付金など。使うには一定の条件がある |

※講座の数は編集部調べ（2026年10月10日時点、AI講座21講座）。E資格は日本ディープラーニング協会「E資格とは」（2026年10月11日閲覧）。

迷っているなら、2週間だけ独学で試す。毎日30分（14日で計7時間）、自分の仕事のメールや報告書の下書きを生成AIに作らせ、直した箇所と、止まった箇所をメモに残す。2週間後に、下書きの時間が減っていて止まる箇所も少ないなら、講座は急がなくてよい。止まった箇所が「聞ける人がいれば解ける」ものばかりなら、質問できる講座が向く。30万円前後の講座を考えているなら、そのメモを無料相談に持っていき、止まった箇所を講座で扱うかを聞く。

質問できる相手と期限がほしい場合、たとえば侍エンジニアの業務改善AI活用コースは、専属の講師と週1回60分のレッスンを重ねる。PythonやGAS、ChatGPTで仕事の作業を自動にする方法を学び、8週間プランは23万1,000円（税込・入学金込み）。AI Academy（アガルート）のAI人材コースは、無料のフリープランで一部の教材を試せる。続けるなら、現役エンジニアに50回まで質問できるプラン（6か月で11万5,280円、税込）がある。無料で教材の一部やレッスンを試せる講座は、21講座のうち7講座で確かめた（編集部調べ、2026年10月10日時点）。

さらに詳しく：生成AIは無料でどこまで学べる？　総務省「生成AIはじめの一歩」から各社の公式ガイドまで、独学の順番（お金をかけずに学ぶときの教材と順番が分かる）

## 申し込む前に、広告と規約で確かめること
申込みの画面に進む前に、講座の公式サイト、利用規約、特定商取引法に基づく表記を開いて確かめる。

- 「No.1」や「満足度○%」の注記に、調査機関、時期、答えた人、比べた相手が書いてある
- 合格率や転職成功率の注記に、分母に入る人と集計期間が書いてあり、受講者全体で見た割合を自分で見積もれる
- 受講者の声は運営会社が選んだものと分かったうえで、カリキュラムの一覧と講師への質問の方法を確かめた
- 全額返金の期限、受講開始の意味、途中でやめたときの精算の式を規約で読んだ
- 自動更新なら、退会の締め切りを手帳やカレンダーに書いた
- 特定商取引法に基づく表記に、会社名、住所、電話番号がある
- 割引の期限があっても、規約を読み終えるまでは申し込まない

注記がない、または読んでも分からない点は、メールで問い合わせて答えを文書で残す。電話や面談で聞く場合も、同じ内容をメモして読み上げる。

> 件名：受講前の確認（○○講座）
> 申込みを検討しています。次の3点を教えてください。
> 1. 公式サイトの「受講者満足度No.1」の調査について、調査機関、調査時期、回答者の条件（受講経験の有無）、比べたスクールを知りたいです。
> 2. 転職成功率○%は、受講を始めた人全員を分母にした割合ですか。修了者や転職支援の利用者に限っている場合は、その人数と集計期間を知りたいです。
> 3. 申込み後に自己都合で解約した場合、受講開始の前と後で、それぞれいくら戻りますか。「受講開始」は何の時点を指しますか。

答えがあいまいだったり、返事がなかったりしたら、その講座は候補から外す。
