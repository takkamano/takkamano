職場または学校で Microsoft Copilot Chat を使用する場合のデータ保護
注
Microsoft 365 Copilot Chat の名前は Microsoft Copilot Chat になりました。 Copilot Chat を使用する場合、データ保護に変更はありません。
Microsoft Copilot Chat は、AI 搭載の Web 用チャットを提供します。 業界の分析情報の調査、データの分析、インスピレーションの検索のいずれを行う場合でも、Copilot Chat を使用すると、より優れた回答、より高い効率性、創造性を発揮するための新しい方法にアクセスできます。
データを保護するために、職場または学校アカウントでサインインすると、Copilot Chat はエンタープライズ データ保護を提供します。
Copilot Chat について知っておくべき重要な点を次に示します。
Copilot Chat では、認証に職場または学校アカウントが使用され、そのアカウントでサインインすると、エンタープライズ データ保護が自動的に提供されます。
プロンプトに追加した作業コンテンツを含むプロンプトと Copilot の応答は、基礎モデルのトレーニングには使用されません。
Copilot Chat のチャット データは、チャット セッション中に暗号化されます。
プロンプト、プロンプトによってトリガーされた Bing 検索クエリ、Copilot Chat での応答がログに記録されます。 IT 管理者は、Microsoft の検索ツールと監査ツールを使用して、このログに記録された情報を表示できます。
Copilot Chat は、暴力、生々しいコンテンツ、憎悪に満ちた言葉など、有害なコンテンツからユーザーを保護するのに役立ちます。
Copilot Chat のプロンプトによってトリガーされる Bing 検索クエリは、プロンプトに基づいて通知されたいくつかの単語で構成されます。 これらのクエリは、アカウントまたは organization にリンクされていません。
Bing 検索サービスは Microsoft 365 とは別に動作し、プロンプトや応答に使用されるものとは異なるデータ処理方法を採用しています。 これらのデータ処理の方針は、各ユーザーと Microsoft との間で締結 される Microsoft サービス規約 と、 Microsoft プライバシーに関する声明によってカバーされます。 これは、Microsoft が独立したデータ コントローラーとして機能し、適用されるすべての法規およびコントローラーに対する義務に準拠する責任を負うことを意味します。 このアプローチは、 Bing に依存する他のオプションの接続エクスペリエンスと一貫しています。
