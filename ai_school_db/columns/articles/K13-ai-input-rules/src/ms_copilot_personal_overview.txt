個人向けの Microsoft Copilot: データ、プライバシー、責任ある AI
重要
Web、デスクトップ、モバイル デバイス用の Microsoft Copilot アプリの更新バージョンは、2026 年 8 月 18 日より利用可能です。 Microsoft Copilot アプリの新しいバージョンに更新またはダウンロードしていない場合、この記事は適用されません。 代わりに、「Microsoft Copilot のプライバシーに関する FAQ」を参照してください。
注
この記事は、Web、デスクトップ、またはモバイルで Microsoft Copilot アプリを使用する際に、個人用メール アドレスなどの Microsoft アカウントでサインインする場合にのみ適用されます。 Microsoft 365 アプリで Copilot を使用している場合は、「 家庭向け Microsoft 365 アプリの Copilot: データとプライバシー」を参照してください。
この記事は、職場、学校、または組織 (Microsoft Entra) アカウントで Microsoft Copilot アプリにサインインする場合、または Microsoft 365 アプリで Copilot を使用する場合には適用されません。 詳細については、「職場または学校で Microsoft Copilot を使用する場合のデータ保護」を参照してください。
Microsoft Copilot は、アイデアから完成した作業まで、すべてを 1 か所で行うのに役立ちます。 Copilot は Word、Excel、PowerPoint、Outlook、Teams などに統合されており、使用するファイルと情報を 1 つのエクスペリエンスにまとめます。 Copilot は、洗練されたドキュメント、プレゼンテーション、スプレッドシートの作成、メールの下書き、1 日の整理、作業中の作業に基づいた回答を得るのに役立ちます。 Cowork を使用すると、Copilot はより大きな複数ステップのタスクを支援し、完了した To Do を提供することもできます。 また、さまざまな種類の作業に対応する主要な AI モデルから選択することもできます。 特定の機能はサブスクリプションによって異なります。
個人用 Microsoft アカウントを使用して Copilot にサインインする場合、Copilot の使用には Microsoft サービス規約 と Copilot の使用条件が適用されます。 Microsoft が従業員の個人データをどのように使用するかについては、「 Microsoft プライバシー ステートメント」をご覧ください。
