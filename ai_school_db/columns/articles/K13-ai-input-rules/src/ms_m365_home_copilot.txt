自宅向け Microsoft 365 アプリの Copilot: データとプライバシー
注
この記事は、Microsoft 365 Personal、Family、Premium、Pro プランなど、家庭向け Microsoft 365 アプリで Microsoft 365 Personal を使用している場合にのみ適用されます。
"自宅用" とは、Microsoft アカウントでサインインしている場合を意味します。 たとえば、個人用のメール アドレスなどです。
詳細については、「 Copilot in Microsoft 365 サブスクリプションについてよく寄せられる質問」を参照してください。
Microsoft Copilot アプリのプライバシーの詳細については、「個人向けの Microsoft Copilot: データ、プライバシー、責任ある AI」を参照してください。
Copilot は、Microsoft 365 アプリでさまざまなタスクやアクティビティを支援するために設計された AI アシスタントです。 たとえば、Word、PowerPoint、Excel、Outlook、または OneNote の場合です。
Microsoft 365 アプリの Copilot は、 Microsoft サービス契約の対象となります。 Microsoft が従業員の個人データをどのように使用するかについては、「 Microsoft プライバシー ステートメント」をご覧ください。
データと Copilot
"プロンプト" とは、Copilot にサポートを依頼する内容です。Copilot が提供する答えは "応答" です。「アクティビティ履歴」は、それらのプロンプトと応答の記録です。
Copilot は、作業中のファイル内のコンテンツ、または確認を求めた別のファイルのコンテンツのみを使用します。 たとえば、Word 文書内の段落を書き直すよう Copilot に依頼する場合や、OneNote のノートから To Do リストを生成するよう Copilot に依頼する場合などが該当します。
重要
Microsoft 365 アプリで Copilot を使用する場合のプロンプト、応答、ファイル コンテンツは、基礎モデルのトレーニングには使用されません。
お客様からのフィードバックを他の Microsoft 365 サービスや Microsoft 365 生産性アプリを改善するために使用するのと同様に、Microsoft 365 アプリの Copilot を改善するためにオプションのカスタマー フィードバックを使用する場合があります。 このフィードバックは、Copilot in Microsoft 365 Apps で使用される基礎モデルのトレーニングには使用されません。 詳細については、「Microsoft 365 アプリでの Microsoft Copilot に関するフィードバックの提供」を参照してください。
Microsoft 365 の接続エクスペリエンスを使用して収集された個人データは、Microsoft 365 Copilot で使用されるものを含め、大規模言語モデル (LLM) のトレーニングには使用されません。
一部のアプリでは、アプリを閉じて再度開いた後でもアクティビティ履歴を確認できます。 たとえば、Windows、Mac、モバイル デバイスの Word、Excel、PowerPoint の場合や、それらのアプリの Web バージョンを使用している場合です。 Copilot のアクティビティ履歴をエクスポートするには、 プライバシー ダッシュボードで Copilot アクティビティ履歴を管理するを参照してください。
一部のアプリまたは特定の種類のデバイスでは、アプリを閉じて再度開いた後、Copilot にアクティビティ履歴が表示されません。 そのような場合は、アプリを開くたびに、Copilot で最初からやり直しすることになります。
プライバシー設定と Copilot
Microsoft 365 アプリを使用しているときに、 プライバシー設定 を選択できます。 Copilot 機能を使用できるかどうかは、次の 2 つの設定によって異なります:
コンテンツを分析するエクスペリエンス
すべてのコネクテッド エクスペリエンス
これらの設定のいずれかをオフにすると、次のアプリで Copilot 機能を使用できなくなります。
Excel
OneNote
Outlook
PowerPoint
Word
これは、Windows、Mac、iOS、または Android デバイスでこれらのアプリの最新バージョンを実行している場合に適用されます。
これらの設定により、使用したい他の機能もオフになります。 詳細については、「 Microsoft 365 の接続エクスペリエンス」を参照してください。
