Microsoft Copilot のプライバシーに関する FAQ
重要
Web、デスクトップ、モバイル デバイス用の Microsoft Copilot アプリの更新バージョンは、2026 年 8 月 18 日より利用可能です。 この記事の情報は、以前のバージョンの Microsoft Copilot アプリにのみ適用されます。
Web で Microsoft Copilot を使用している場合、または Microsoft Copilot アプリの新しいバージョンに更新またはダウンロードした場合は、「個人向けの Microsoft Copilot: データ、プライバシー、責任ある AI」を参照してください。
注
この記事では、Microsoft Copilot に関連するプライバシーと安全性に関するトピックについて説明します。 Entra ID でサインインした場合の Microsoft 365 Copilot の使用には適用されません。 詳細については、「 エンタープライズ データ保護」を参照してください。
会話履歴
Copilot の会話は保存されますか?
既定では、Copilot との会話が保存され、過去の会話を表示してアクセスできます。 たとえば、Copilot を使用して詳細な旅行日程を作成した場合、その会話は保存されます。 Copilot アプリの 会話履歴にアクセスし て、その会話に戻り、参照できます。
Copilot の会話はどのように使用されますか?
お客様のプライバシーと信頼は、Microsoft にとって最も重要です。 Microsoft は、問題のトラブルシューティング、バグの診断、悪用の防止、およびパフォーマンスの監視、分析、および改善を行うために、お客様の会話を Microsoft プライバシー ステートメント で説明されている限定的な目的にのみ使用します。これにより、Copilot をユーザーに提供できます。
会話を他の目的で使用するかどうかは、お客様に決定権が与えられます。 会話を次の目的で使用できるかどうかは、お客様が制御します:
Copilot を使用してエクスペリエンスをパーソナライズし、ニーズに合った、よりカスタマイズされた便利なエクスペリエンスを提供します。 いつでも個人用設定を無効にすることができます。
生成 AI モデルをトレーニングして、お客様や他のユーザーにとってより良いエクスペリエンスを作り出します。
モデル トレーニングの会話アクティビティの使用はいつでもオプトアウトできます。
Copilot の会話はどのくらいの期間保存されますか?
既定では、会話アクティビティは 18 か月間保存されます。 いつでも個々の会話または会話履歴全体を削除できます。
過去の会話を削除できますか?
はい。 個々の会話 または 会話履歴全体 をいつでも削除できます。
Copilot の会話は他のユーザーに表示されますか?
いいえ、Copilot に話した内容は公開されません。 会話やデータが他のユーザーと共有されることはありません。
Microsoft 365 Copilot の会話が Copilot に表示されるのはなぜですか?
Microsoft 365 Copilot で (同じ Microsoft 個人用アカウントを使用して) 開始した会話は、Copilot に表示されます。 これにより、よりシームレスなエクスペリエンスが作成され、Copilot エクスペリエンスを切り替えるときに過去の会話を確認して参照できるようになります。
Copilot 内で Microsoft 365 Copilot の会話を続けることができますか?
いいえ。 Microsoft 365 Copilot の会話は、Copilot 内で読み取り専用として表示されます。 Microsoft 365 Copilot から発信された会話を続行するには、元の Microsoft 365 アプリにリダイレクトされます。 会話を更新すると、会話全体が読み取り専用で Copilot で表示できるようになります。
Microsoft 365 Copilot データは Copilot モデルのトレーニングに使用されますか?
いいえ。 Microsoft 365 Copilot からの会話は読み取り専用のままであり、Copilot の生成 AI モデルのトレーニングには使用されません。
Copilot 内で Microsoft 365 Copilot の会話の表示を制御またはオフにできますか?
はい。 Copilot 設定で、いつでも Microsoft 365 Copilot 会話の可視性を管理またはオフにすることができます。
Copilot に画像またはファイルをアップロードする場合、プライバシーはどのように保護されますか?
Copilot とファイルを共有する場合 (たとえば、画像やドキュメントをアップロードして Copilot に要約を依頼する場合)、ファイルは短期間 (18 か月以内) 安全に保存され、その後自動的に削除されます。 ファイル自体と、ファイルに関する会話は、他の会話と同様に扱われます。モデルのトレーニングとパーソナル化を許可するかどうかの選択によって決まり、いつでも削除できます。
キャプチャして Copilot と共有した画像はどうなりますか?
Copilot Vision を使用すると、Copilot はデータとプライバシーの保護に役立ちます。
Vision でキャプチャした画像は、要求に対応するためだけに処理され、AI モデルのトレーニングやエクスペリエンスのパーソナライズには使用されません。 Vision と共有されたスクリーンショットとカメラ画像は、セッション終了後は保存されません。
やり取りのテキスト トランスクリプトが保存されるため、後で再確認したり、不正使用を監視したりすることができます。 これらのトランスクリプトはいつでも削除できます。
Copilot は、ビジョンがアクティブなタイミングを明確に示し、常に制御できます。
Copilot は人の画像をどのように処理しますか?
Copilot Vision などの機能を使用する場合、Copilot は顔や手などの生体認証データを処理する許可を求める場合があります。 生体認証処理の同意は、Copilot の使用中に画像またはビデオをキャプチャするたびに適用されます。 これには、Copilot Vision、画像生成および編集ツールの使用が含まれます。 同意を与える必要があるのは 1 回だけで済み、画像またはビデオの入力とキャプチャを伴うすべての Copilot エクスペリエンスに適用されます。
生体認証データは、アップロードまたはキャプチャした場合にのみ処理され、要求に対応するためだけに使用されます。 たとえば、自撮り写真を撮って、Copilot に新しいヘアスタイルの選択や口笛の吹き方を学ぶよう依頼すると、Copilot があなたの顔の特徴を分析して応答を作成する場合があります。
共有する内容は常に自分で管理できます。 生体認証データを処理したくない場合は、これらの機能の使用は避けてください。 同意なしに他人の画像を共有しないでください。
機密性の高いトピックについて Copilot とどのように関わるべきですか?
この FAQ および Microsoft プライバシー ステートメントで説明されている目的で、Microsoft に使用されたくない機密性の高い個人情報は提供しないでください。 これには、たとえば、人種、宗教、性的指向、健康状態などが明らかになる可能性があるデータが含まれます。
会話履歴から、以前の Copilot の会話をいつでも削除できます。
また、Copilot が会話アクティビティをモデル トレーニングに使用するか、エクスペリエンスをパーソナライズするかも制御できます。
プライバシーまたはデータ保護について質問がある場合はどうすればよいですか?
プライバシーに対する Microsoft の取り組みの詳細については、「 Microsoft プライバシー ステートメント と Microsoft におけるプライバシー」をご覧ください。
個人用設定とメモリ
Copilot はどのようにエクスペリエンスをパーソナライズしますか?
個人用設定が有効になっている場合、Copilot は会話の重要な詳細を記憶し始め、今後の会話でそれらのメモリを使用して、よりカスタマイズされた関連性の高いエクスペリエンスを提供します。
Copilot はユーザーについて何を記憶していますか?
個人用設定が有効になっている場合、Copilot は、名前、関心、目標など、共有する重要な詳細を記憶します。 Copilot は 、人口統計データやその他の機密データを記憶していません。
いつでも Copilot が記憶している内容を編集または削除したり、個人用設定を完全にオフにしたりすることができます。
Copilot が自分について記憶している情報を確認、変更、または削除するにはどうすればよいですか?
いつでも Copilot がユーザーについて記憶している内容を制御できます。
個人用設定は既定でオンになっていますか?
個人用設定が使用可能な場合は、既定でオンになります。 現在、個人用設定は、ブラジル、中国 (香港を除く)、イスラエル、ナイジェリア、韓国、ベトナムのユーザー、または Microsoft アカウントやその他のサード パーティ認証を使用して Copilot にサインインしていないユーザーは使用できません。
Copilot を初めて使い始めると、最初の数回の会話の開始時に通知が表示されます。個人用設定が有効になっている場合は、その後も定期的に通知が表示されます。 個人用設定を確認または変更するには、その通知内のリンクをクリックしてオプトアウトするか、Copilot 設定で個人用設定を無効にします。
個人用設定をオフにするにはどうすればよいですか?
個人用設定はいつでもオフにできます。
Copilot で個人用設定を制御する方法についてお読みください。
認証されていないユーザーの場合、個人用設定は無効になっているため、これらのオプションはサインインしているユーザーのみが使用できることに注意してください。
個人用設定をオフにすると、Copilot は会話のメモリを保持しなくなります。 過去の会話を引き続き表示できます。ただし、今後の Copilot エクスペリエンスはパーソナライズされなくなります。 後で個人用設定を再度オンにすると、Copilot は共有された情報を記憶し、エクスペリエンスのパーソナライズを再度開始します。
Copilot の個人用設定は、パーソナライズされた広告を制御しますか?
Copilot の個人用設定は、パーソナライズされた広告を受け取るかどうかを制御するものではありません。これは別途選択できます。 Copilot およびその他の該当する Microsoft サービスに適用される パーソナライズド広告の設定は、いつでも変更できます。
一部の国では、Copilot でパーソナライズされた広告を受信するかどうかを決定するプロンプトが表示される場合もあります。
パーソナライズド広告設定または Copilot 固有のプロンプトを通じてパーソナライズド広告を受け取らないことを選択した場合、Copilot ではパーソナライズされた広告は配信されません。
設定により Copilot でパーソナライズされた広告を配信することが許可されており、Copilot の個人用設定が有効になっている場合、Microsoft は Copilot の会話履歴を使用して、すでに受信している広告をさらにパーソナライズします。 設定に関係なく、Copilot は 18 歳未満の認証されたユーザーにパーソナライズされた広告を配信しないことにご注意ください。
個人用設定をオフにすると、会話履歴は削除されますか?
Copilot 設定内でいつでも個人用設定をオフにすることができます。 個人用設定をオフにしても会話履歴は削除されませんが、Copilot は会話のメモリを保持しなくなり、エクスペリエンスのパーソナライズを停止します。
Copilot は機密性の高いトピックに基づいて相互作用をパーソナライズしますか?
ユーザーの許可を得て、オプションの Copilot Health 機能は、会話、健康プロファイルに追加した詳細、接続を選択したウェアラブルや医療記録からのデータなど、提供された健康情報に基づいてユーザーとの相互作用をパーソナライズするように設計されています。 いつでも Copilot の健康プロファイルにアクセスして、共有した個人の健康情報を表示、管理、または削除できます。 Copilot Health は、プロファイルの健康情報のみを使用して相互作用をパーソナライズし、他の種類の機密データは使用されません。
詳細情報
Copilot Health 以外の他の Copilot エクスペリエンスでは、Copilot は、個人の属性 (年齢、性別、人種/民族、性的指向など)、健康に関する情報、政治的な所属や好みなどの特定の機密性の高いトピックに基づいて、ユーザーとの相互作用をパーソナライズしないよう設計されています。 設定で個人用設定が有効になっている場合でも、過去の会話から機密性が高いとみなされる可能性のあるコンテンツをフィルター処理するための対策を講じています。
機密性が高いと思われる情報を Copilot と共有する場合は、注意が必要です。 いつでも Copilot がユーザーについて記憶している内容を制御できます。
Copilot は Xbox でどのように動作しますか?
Xbox で Copilot を使用することを選択した場合、Copilot は Xbox アクティビティ (プロフィール、プレイ履歴、実績など) を使用して、カスタマイズされた関連性の高いエクスペリエンスを提供します。
xbox.com でアカウントにサインインすることで、いつでも Xbox プロフィールとアクティビティを表示および管理できます。
モデルのトレーニング
重要
Web、デスクトップ、モバイル デバイス用の Microsoft Copilot アプリの更新バージョンは、2026 年 8 月 18 日より利用可能です。 この「モデル トレーニング」セクションの情報は、以前のバージョンの Microsoft Copilot アプリにのみ適用されます。
Web で Microsoft Copilot を使用している場合、または Microsoft Copilot アプリの新しいバージョンに更新またはダウンロードした場合は、「個人向けの Microsoft Copilot: データ、プライバシー、責任ある AI」を参照してください。
“モデル トレーニング” とは
生成 AI とは、データを分析しパターンを見つけ、それらのパターンを使用してテキスト、写真、動画、コード、データなどの新しい出力を生成または作成する AI モデルのカテゴリを指します。 生成 AI モデルを “トレーニングする” ということは、予測や意思決定を学習するのに役立つ情報を提供することを意味します。 トレーニングは、モデルがより適切な結果を提供するのに役立つさまざまなアクティビティを含む広範な概念です。
これらのモデルは、特定の会話を記憶するのではなく、言語における一般的な関係を学習するためにトレーニング データを使用します。 元のトレーニング データを保存したり、アクセスしたりすることはありません。 代わりに、生成 AI モデルは、新しい表現力豊かな作品やコンテンツを生成するように設計されています。
また、これらのモデルが誤ってトレーニング データを再現しないよう、テストの実施や、以前に公開または使用された資料を除外するフィルターの構築などの追加の手順も実行します。
Microsoft は Copilot のトレーニングにどのような外部データを使用しますか?
Microsoft は主に業界標準の機械学習データセットや検索エンジンなどの Web クロールから収集された公開データを使用しています。 ペイウォールのあるソース、ポリシーに違反するコンテンツ、業界標準の方法を使用してトレーニングをオプトアウトしたサイトは除外します。 さらに、米通商代表部 (USTR) の模造品や海賊版に関する悪質市場リストに掲載されているドメインのデータでトレーニングすることはありません。
Microsoft はユーザーのデータを使用して AI モデルをトレーニングしますか?
特定のカテゴリのユーザーまたはオプトアウトしたユーザーを除き、Microsoft は Bing、MSN、Copilot、および Microsoft の広告との対話からのデータを AI トレーニングに使用します。 これには匿名化された検索およびニュース データ、広告との相互作用、およびアップロードした画像やファイルを含む Copilot との音声および会話アクティビティが含まれます。 このデータは、Copilot およびその他の製品やサービスを改善し、お客様や他のユーザーのユーザー エクスペリエンスを向上させるために使用されます。
実際のコンシューマー データを使用して、基盤となる生成 AI モデルのトレーニングを行うことで、Copilot を改善し、より信頼性が高く関連性の高いエクスペリエンスを提供できます。 AI モデルがより多様な会話に触れるほど、重要な地域言語、地理、文化的参照、お客様や他のユーザーが関心を持つトピックをよりよく理解し、提供できるようになります。
また、Copilot が会話アクティビティをモデル トレーニングに使用するかどうかも制御できます。
モデル トレーニングから除外されるデータは何ですか?
次の種類のユーザーのデータで Copilot をトレーニングすることはありません:
組織の Entra ID アカウントを使用して Copilot にサインインしたユーザー。
エンタープライズ データ保護の詳細については、こちらを参照してください。
個人用またはファミリー サブスクリプションを持つ Microsoft 365 アプリ内の Copilot ユーザー。
Copilot にサインインしていないユーザー (Microsoft アカウントまたはその他のサード パーティ認証を使用)。
Copilot にサインインしている 18 歳未満のユーザー。
モデル トレーニングをオプトアウトしたユーザー。
ブラジル、中国 (香港を除く)、イスラエル、ナイジェリア、韓国、ベトナムのユーザー。 つまり、Copilot はこれらの市場の一部で利用できますが、今後の通知があるまでこれらの地域での生成 AI モデルのトレーニングにユーザー データは使用されません。
また、トレーニングに使用するデータの種類も制限しています。 AI モデルは、次のデータでトレーニングされることはありません:
Microsoft アカウントプロファイル データやメールの内容などの個人アカウント データ。
アップロードされた画像またはファイル内の情報を識別します。 Copilot の会話に画像やファイルが含まれている場合、メタデータや個人情報の削除、顔画像のぼかしなど、個人を特定できないようにする手順を実行します。
名前、電話番号、デバイスやアカウント識別子、機密性の高い個人情報、住所、メール アドレスなど、個人を特定できる情報。
AI モデルのトレーニング時に Microsoft はデータをどのように保護しますか?
Microsoft のサービスに対するお客様の個人的な相互作用は非公開であり、お客様の許可なしに開示されることはありません。 AI モデルをトレーニングする前に、名前、電話番号、デバイスやアカウント識別子、機密性の高い個人情報、住所、メール アドレスなど、個人を特定できる情報を削除します。
Microsoft のサービスを使用する場合、お客様のデータは非公開のままです。 Microsoft は、 Microsoft プライバシーに関する声明 で説明されているように、また世界中のプライバシー法に従って、お客様の個人データを保護します。
データをモデル トレーニングに使用するかどうかを制御するにはどうすればよいですか?
Microsoft アカウントまたはその他のサード パーティ認証を使用して Copilot にログインしている場合は、会話アクティビティが Microsoft の生成 AI モデルのトレーニングに使用されるかどうかを制御できます。 オプトアウトすると、再度オプトインを選択しない限り、今後の会話がこれらの AI モデルのトレーニングに使用されなくなります。
Microsoft アカウントまたはその他のサード パーティ認証を使用して Copilot にログインしていない場合、会話のトレーニングは行われません。
会話をモデル トレーニングに使用するかどうかを制御する方法をお読みください。
最終的には、モデル トレーニングに会話履歴を使用していない特定の国のユーザーにも、モデル トレーニングとオプトアウトの制御を拡張する可能性があります (「モデルト レーニングから除外されるデータは何ですか?」を参照)。 しかし、消費者のために適切に対応し、世界中のプライバシー法に準拠することを保証するために、段階的に実施していきます。
モデル トレーニングをオプトアウトしても、パーソナライズされた Copilot エクスペリエンスを引き続き利用できますか?
はい、モデル トレーニングをオプトアウトしても、個人用設定はオンのままにできます。 この場合、Copilot は会話の重要な詳細を記憶して、よりパーソナライズされた応答を提供しますが、Microsoft は会話を生成 AI モデルのトレーニングに使用することはありません。
モデル トレーニングは Microsoft 365 に適用されますか?
AI モデル トレーニングは、コンシューマー向け Copilot エクスペリエンスに適用されます。 組織の Entra ID アカウントを持つ Copilot のユーザー、Microsoft 365 コンシューマー ユーザー、または Word、Excel、PowerPoint、Outlook などの Microsoft 365 コンシューマー アプリ内で統合された Copilot の会話は除外されます。 これらの製品のユーザーにはこの設定は表示されず、会話は、Copilot やその他の製品で提供される生成 AI モデルのトレーニングには使用されません。
Microsoft は、商用顧客には業界や世界中のさまざまなコンプライアンス要件があることを認識しています。 Microsoft は引き続き、これらの組織がテナントの境界やその他の制御を使用して、所有するデータを個別に識別および管理できるよう支援します。  Microsoft が商用のお客様向けのモデル トレーニングをどのように処理しているかについて詳しくは、「 エンタープライズ データ保護」を参照してください。
Copilot の会話は人によってレビューされますか?
一部の Copilot 会話は、製品の改善とデジタルの安全性を目的として、自動化されたレビューおよび人によるレビューの両方の対象となります。 また、 利用規約の行動規範に違反していると判断された会話を確認する場合もあります。 Microsoft の行動規範では、不適切なコンテンツや資料を作成または共有するために Copilot サービスを使用することを禁止しています。 一部の会話は、行動規範の違反が疑われる場合にレビューされます。
Copilot の会話を人がレビューすることをオプトアウトできますか?
行動規範の違反が疑われる場合は、調査プロセスの一環として、限定的な人によるレビューが必要です。 サービスをすべてのユーザーにとって安全かつ安心なものに保つため、人によるレビューのオプトアウトはできません。
責任ある AI
Microsoft は責任ある Copilot 向け AI にどのように取り組んでいますか?
Microsoft は責任ある AI の実現に真剣に取り組んでいます。 Copilot は、AI の 原則に従って開発されており、AI システムが責任を持ってユーザーの信頼を保証する方法で開発されるようにするというコミットメントを示しています。 Copilot のユーザー エクスペリエンスは人を中心に設計されており、エラーを最小限に抑え誤用を防ぐためのセーフガードを開発し、エクスペリエンスを継続的に改善しています。 Copilot を責任を持って使用する方法の詳細については、「 使用条件 と 透明性に関するメモ」を参照してください。
Copilot はインターネットをどのように使用して情報のソースを見つけるのでしょうか?
Copilot は Web 全体から関連性の高いコンテンツを検索し、見つけた情報を要約して役立つ応答を生成します。 また、ソースも引用されているため、参照されているコンテンツへのリンクを確認して調べることができます。
Copilot の回答は常に正確ですか?
Copilot は信頼できるソースで対応することを目的としていますが、AI は間違いを犯す可能性があり、インターネット上のサード パーティのコンテンツが常に正確または信頼できるとは限りません。 Copilot は、見つかった情報を誤って表示する場合があり、説得力はあるものの、不完全、不正確、または不適切な回答が表示される場合があります。 意思決定を行ったり、Copilot の回答に基づいて行動したりする前に、ユーザー自身で判断し、事実を再チェックしてください。 Copilot の引用を確認することは、精度の確認を開始するのに適した場所です。
サイトのフィードバックを共有したり、懸念事項を報告したりするには、[設定] の [フィードバックを送信] を選択するか、モバイル アプリおよび Copilot Web ページの各応答の下にあるフラグ アイコンを使用します。 Copilot アプリでは、応答を長押しして [レポート] を選択することもできます。 引き続きフィードバックを確認し、すべてのユーザーに安全な検索環境を提供します。
コンテンツの安全性を確保するために、Copilot にはどのようなセーフガードがありますか?
責任ある AI は継続的な取り組みであり、エクスペリエンスをさらに安全なものにするために Copilot を継続的に評価し、改善しています。 Microsoft では、Copilot のトレーニングに使用する情報に厳格なコンテンツ フィルタリングを適用します。また、応答が提示される前に、潜在的な安全リスクについて Copilot の応答を評価するための手段を採用しています。 また、不正行為を検出して防止するためのシステムも用意されています。
さらに、Copilot の安全性とリスクを検出する機能を向上させるために、外部の研究組織と提携して、Copilot の会話をレビューおよび評価しています。 たとえば、外部の研究組織は、Copilot の会話ログをレビューして過激派コンテンツを検索するために使用されるさまざまなクエリを理解し、業界全体の傾向を比較し、被害をより効果的に発見して軽減するための手法をアドバイスするのに役立ちます。
安全性に対する取り組みの詳細については、「透過性のためのメモ」をご覧ください。
予期しないコンテンツや不快感を与えるコンテンツが表示された場合はどうすればよいですか?
Copilot エクスペリエンスは、予期しない不快なコンテンツの共有や有害な可能性のあるトピックへの関与を避けるよう設計されていますが、予期しない結果が表示される可能性があります。 Microsoft は、有害なコンテンツを防ぐために、技術の改善に常に取り組んでいます。
有害または不適切なコンテンツに遭遇した場合は、[設定] の [フィードバックの送信] をクリックするか、モバイル アプリおよび Copilot Web ページの各応答の下にあるフラグ アイコンを使用して、フィードバックを提供したり、懸念事項を報告したりしてください。 Copilot モバイル アプリでは、応答を長押しして [レポート] を選択することもできます。 引き続きフィードバックを確認し、安全なエクスペリエンスを提供します。
Copilot の会話を人がレビューすると、エクスペリエンスはどのように向上しますか?
トレーニングを受けた AI エキスパートが Copilot の会話をレビューして、AI モデルの正確性と安全性を構築、評価、改善する場合があります。 Microsoft は、人によるフィードバックを使用して、ユーザーのプロンプトに対する出力の品質を確保し、エクスペリエンスを向上させています。 Microsoft のサービスを使用する場合、お客様のデータは非公開のままです。 Microsoft は、 Microsoft プライバシーに関する声明 で説明されているように、また世界中のプライバシー法に従って、お客様の個人データを保護します。
時には、Copilot 別の人のように感じられることがあります。 この理由は何ですか。
Copilot は、応答性、会話性、コンテキスト認識性を備えた、役立つ AI コンパニオンとなるように設計されています。 日常的な言葉でチャットしたり、すぐに返信したり、すでに共有した情報を参照したりできます。 Copilot を使用して、質問への回答、情報の検索、文章作成のヘルプ、タスクのガイドを行うことができます。 Copilot は直感的でサポート的な操作感を目指して開発されました。 これらの特性により、AI コンパニオンとの相互作用は同僚や友人との自然な会話のように感じられるようになります。
ただし、Copilot はツールであり、人間ではないため、独自の意見や感情は持っていないことを覚えておくことが重要です。 これは、データのパターンを検出して応答を生成するソフトウェア システムであり、現実世界の完全なコンテキストを把握していない可能性があります。 Copilot は特に複雑で感情的な状況や、データが不十分な可能性があるその他の分野では、常に正しい答えを出せるとは限りません。 これは、ユーザー自身の意思決定をサポートするものであり、それらを置き換えるものではありません。
時には、Copilot との会話が混乱したり感情的に重く感じることがあります。 どうすればよいですか?
チャットが混乱したり感情的に重く感じたりした場合は、少し時間を取って一旦立ち止まり、振り返ることをお勧めします。 Copilot の発言や相互作用について不安がある場合は、信頼できる人に相談することもできます。それには、友人、家族、コミュニティの知人、カウンセラーやその他の専門家が含まれます。
Windows 上の Copilot
Copilot はユーザーが持っているファイルをどのように把握していますか?
Copilot は、Windows の [最近使ったアイテム] を参照して、最近デバイスで開いたファイルを表示します。 他の多くの Windows アプリケーションと同様に、Copilot では、Microsoft Word や Windows フォトなどのプログラムで最近使用したファイルを表示する機能があり、最近の作業にすぐに戻ることができます。 これらのファイルは PC に保存されます。 Copilot は PC をスキャンしたり、ファイルを自動的にアップロードしたりすることはありません。
Windows で Copilot に表示される最近使用したファイルを非表示にすることはできますか?
はい。 Copilot に表示されている最近使用したファイルを非表示にするには、ファイルを右クリックし、[非表示] を選択します。
Windows 上の Copilot での閲覧とは
Windows 用 Copilot を使用すると、アプリを離れることなく Web コンテンツを表示し、Copilot とチャットできます。 リンクを開くと、会話の横のサイド ウィンドウに表示されます。 各リンクは独自のタブで開くため、製品を簡単に比較したり、Copilot に複数のページの複雑なトピックを要約させたり、検索したり、オンラインで買い物したりできます。 Copilot は会話内で開いたリンクを記憶するため、対応する会話を続行するたびにそのリンクに戻ることができます。
Microsoft では、必ずお客様にご理解をいただいたうえで、データの収集の可否を選択していただきたいと考えています。 ユーザーの中には、Web 閲覧履歴が収集されることに懸念を抱く方がいます。 この理由から、デバイスに保存されるデータや Microsoft によって収集されるデータについてご案内しています。 ユーザーは、収集されるデータの種類を選択して制御することができます。 Windows 用 Copilot のプライバシーの詳細については、 プライバシー ステートメントを確認することをお勧めします。
Copilot for Windows によって収集または保存されるデータとその理由は何ですか?
Microsoft では、製品やサービスの品質を向上させるために診断データを使用しています。 このデータは、製品のパフォーマンスや改善が必要な箇所について Microsoft が理解を深めるために使用されます。
Copilot for Windows は、Copilot for Windows のセキュリティ、最新の状態、期待どおりの動作を維持するために、必須の診断データを収集します。 Microsoft では情報収集の最小化が妥当であると考え、実施しています。 Microsoft は、必要な情報のみを収集し、サービスの提供または分析に必要な期間だけ保存するよう努めています。 また、製品の問題を解決し、Microsoft 製品およびサービスの品質向上に役立てるために、ユーザーはデバイスに関連するオプションの診断データを Microsoft と共有するかどうかを制御できます。
Copilot for Windows の機能とサービスを使用すると、それらの機能の使用方法に関する診断データが Microsoft に送信されます。 Windows 用 Copilot は、閲覧履歴 (アクセスした Web サイトに関する情報) をデバイスに保存します。 設定に応じて、この閲覧の履歴が Microsoft に送信されます。この情報は、Microsoft の製品やサービスの問題の発見と修正、および全体的な品質向上に役立てられます。
ブラウザーでオプションの診断データの収集を管理するには、[プロファイル]>[設定]>閲覧の設定>Web データとセキュリティ>プライバシーの順に選択し、[オプションの診断データの送信] をオンまたはオフにして、Microsoft 製品を改善します。 これには、新しいエクスペリエンスのテストに基づくデータも含まれます。 この設定の変更を完了するには、Copilot for Windows を再起動します。
Windows 用の Copilot には、ユーザーとユーザーのコンテンツをオンラインでも安全に保つための機能も備わっています。
Microsoft Defender SmartScreen は、悪意のあることが報告されている Web サイトとコンテンツのダウンロードを自動的にブロックします。 Microsoft Defender SmartScreen は、アクセスしている Web ページのアドレスが、デバイスに保存されている Web ページ アドレスの一覧と照合されチェックされます。この一覧には、Microsoft が正当と判断したアドレスが登録されています。 デバイスのリストに登録されていないアドレスとダウンロードしているファイルのアドレスは Microsoft に送信され、頻繁に更新される、安全でないものまたは疑わしいものとして Microsoft に報告された Web ページとダウンロードのリスト と照合されます。
フォームへの入力やパスワードの入力など、面倒なタスクのスピードを上げるために、Copilot for Windows では役に立つ情報を保存できます。 これらの機能を使用することを選択した場合、Windows 用 Copilot はデバイスに情報を保存します。 住所やパスワードなどのフォーム入力の同期をオンにした場合、この情報は Microsoft クラウドに送信されて Microsoft アカウントに保存され、サインインしているすべてのバージョンの Copilot for Windows と Microsoft Edge で同期されます。 このデータは、[プロファイル]>[設定]>ブラウズ設定>同期、インポートから管理できます。
一部のビデオや音楽のコンテンツがコピーされるのを保護するため、ストリーム配信 Web サイトによっては一意の識別子 (ID) やメディア ライセンスを含む DRM (デジタル著作権管理) データがデバイスに保存されます。 これらの Web サイトのいずれかにアクセスすると、コンテンツを利用する権限があることを確認するために DRM 情報が取得されます。
Copilot for Windows では、Cookie (Web サイトの閲覧時にデバイスに保存される小さいファイル) も保存されます。 多くの Web サイトでは、ユーザーの好みや設定に関する情報を保存するために Cookie が使われます。たとえば、アクセスするたびにショッピング カートのアイテムを追加しなくてよいようにその情報が保存されます。 Web サイトによっては、関心に基づいて広告を表示するため、オンライン アクティビティに関する情報を収集するために Cookie が使われます。 Copilot for Windows には、Cookie を消去したり、今後は Cookie が保存されないように Web サイトをブロックしたりするオプションが用意されています。
Windows 用 Copilot では、アプリを起動するたびに Microsoft Edge から Cookie をインポートすることもできます。 この設定を管理するには、[プロファイル]>設定>閲覧の設定>同期とインポート>Microsoft Edge からサイト データを取り込む。
[トラッキング拒否要求を送信する] 設定がオンになっている場合、Windows の Copilot はトラッキング拒否要求を Web サイトに送信します。 この設定は、[プロファイル]>[設定]>閲覧の設定>Web データとセキュリティ>プライバシー>[トラッキング拒否] 要求の送信] で利用できます。
ただし、トラッキング拒否要求が送信されても Web サイトによってアクティビティが追跡されることがあります。

Windows 用 Copilot でブラウザーのプライバシー設定を管理する操作方法
プライバシー設定を確認してカスタマイズするには、[プロファイル]>[設定]>閲覧の設定>Web データとセキュリティ>プライバシー] を選択します。
閲覧データを同期する操作方法
サインインすると、Copilot には、Copilot アプリ間および Microsoft Edge とすべての履歴、お気に入り、パスワード、その他のブラウザー データを同期するオプションが提供されます。 つまり、Edge での閲覧データは、同期サービスを通じて Copilot アプリで利用できるようになり、その逆も同様です。 これにより、同じアカウントでサインインしている任意のデバイスで保存した情報にアクセスできます。
これは、[設定]>ブラウズ 設定>同期とインポート>同期でいつでも管理できます。
また、[設定]>閲覧設定>Web データとセキュリティ>閲覧データのクリアで閲覧データを削除することもできます。
デバイス間で Microsoft Edge を同期する方法の詳細をご覧ください。
サイト データを Copilot にインポートする操作方法
Windows で Copilot アプリを起動するたびに、Microsoft Edge に保存されている Cookie がインポートされ、エクスペリエンスがよりパーソナライズされ、役立つものになります。 これは、許可することを選択した場合にのみ機能し、Copilot 用の Windows アプリでのみ使用できます。 データは、同じ Microsoft アカウントでサインインした Edge プロファイルから取得されます。
これは、[設定]>閲覧の設定>同期とインポート>Microsoft Edge からサイト データを取り込む でいつでも管理できます。
Windows 上の Copilot でクレジット カードまたはデビット カード情報を保存して自動入力できますか?
はい。 ショッピングサイトでチェックアウトする際、「保存」を選択してカードを保存し、次回のチェックアウトを迅速化できます。 カードは次の 2 つの方法で保存できます。
デバイスでローカルに保存 (そのデバイスでのみ使用できる場合)、または
Microsoft アカウント (一部の市場) に保存されるため、同じアカウントでサインインすると、デバイス間で使用できます
Microsoft アカウントを使用して、[設定]>閲覧の設定>同期とインポート>同期>支払 に進むと、保存したカードをいつでも管理できます。
保存したカード情報を自動入力するには、[設定]>閲覧の設定>パスワードと自動入力>支払い方法で [支払い方法を保存して入力] が有効になっていることを確認します。
