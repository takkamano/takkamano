タイトル：「この資料、AIに貼っていい？」と迷ったら　生成AIに入力しない情報の例と、学習に使わせない設定
抜粋：仕事の資料を生成AIに貼ってよいか迷う人へ。入力を控える情報の見分け方、名前や金額を伏せた入力文の改善前と改善後、Gemini・Copilot・Claudeで入力が学習に使われるかの違い、職場で貼る前のチェックリストを載せた。

※この記事は広告（アフィリエイトリンク）を含む。

取引先へのメールや会議のメモを生成AIに貼って、下書きや要約を頼みたい。そう考えて手が止まったなら、勤務先が使ってよいと決めたサービスでない限り、顧客や同僚の個人情報と社外秘の資料は貼らない。個人のアカウントで使う生成AIでは、入力した文章がサービスの改善やAIの学習（集めた文章をもとにAIの答え方を作り直すこと）に使われることがある。学習を止める設定をしても、会話はしばらく保存される。名前や金額を伏せて書き換えれば、多くの作業は個人情報や社外秘を貼らずに頼める。

- 勤務先が使ってよいと決めた法人向けのサービス以外には、個人情報と社外秘の資料を貼らない
- 個人向けのGeminiやClaudeは、学習への利用を設定で止められる。止めても会話は一定の期間残る
- 貼る前に、氏名・社名・金額・連絡先を「A社」「約1割」のように置き換える
- 勤務先にルールがないときや迷うときは、貼る前に上司か情報システム部門に聞く

## 入力した文章は、学習や人の確認に回ることがある
個人向けのGeminiは、設定がオンのあいだ、会話の一部をGoogleの担当者が読み、AIモデルの学習を含む改善に使う。Googleは公式ヘルプ「Gemini アプリのプライバシー ハブ」で、担当者の目に触れて困る機密情報を入れないよう利用者に求めている。

会社などの事業者が生成AIに個人情報を入力するなら、集めたときに決めた利用目的の範囲に収まるかを確かめる（個人情報保護委員会、2023年6月の注意喚起）。顧客名簿や社員名簿のように、検索できる形で整理された個人情報を個人データという。個人データを本人の同意なく入力し、それが回答の作成以外の目的に使われると、個人情報保護法に違反する可能性がある。入力するなら、提供会社がそのデータを機械学習に使わないことなどを先に確かめる。同じ注意喚起は一般の利用者にも、入力した個人情報が学習に使われ、ほかの情報と結びついて、正確な形でも不正確な形でも出力されるおそれを示した。

日本情報システム・ユーザー協会が東証上場企業などのIT部門長に聞いた調査でも、課題の1位は情報の流出だった。文章を扱う生成AIを導入・検討した企業の70.1%が、機密情報の流出を挙げた。

| 生成AIを導入するときの課題（複数回答） | 2025年度 | 2024年度 |
|---|---|---|
| 機密情報の流出 | 70.1% | 69.6% |
| ハルシネーション（もっともらしい誤りを答えること）、信頼性 | 66.4% | 66.6% |
| 権利侵害（回答を使った結果、加害者になるリスクなど） | 50.4% | 53.5% |
| 個人情報などプライバシーの侵害 | 46.5% | 46.8% |

※出典：日本情報システム・ユーザー協会｜企業IT動向調査報告書2026（2026年3月31日発行）。2025年度の調査は2025年9月5日〜10月24日に、東証に上場する企業と、それに準じる企業の計4,500社のIT部門長に依頼し、957社が回答した。表は、言語系生成AI（文章を扱う生成AI）の導入を「未検討」以外と答えた企業（2025年度709社、2024年度647社）の割合。

情報処理推進機構（IPA）の「情報セキュリティ10大脅威 2026」では、組織向けの3位に「AIの利用をめぐるサイバーリスク」が初めて入った。解説書は、職場が認めていない個人のAIサービスを社員が仕事に使う「シャドーAI」を、情報漏えいにつながるリスクに挙げる。持ち出しが禁じられた業務データをそこに入れれば漏えいにつながるため、従業員の対策には、社内の秘密情報をむやみに入力しないことが入っている。

## 貼らない情報は、困る人がいるかで見分ける
顧客の連絡先や同僚の病歴、取引先の単価、発表前の決算のように、社外に出れば本人や会社、取引先が困る情報は、勤務先が認めたサービス以外には貼らない。

| 情報の種類 | 例 | 貼るなら |
|---|---|---|
| 個人を特定できる情報 | 顧客や社員の氏名、住所、電話番号、メールアドレス、社員番号 | 「顧客A」「担当者B」に置き換える |
| 本人が知られたくない情報 | 健康状態や病歴、人事評価、家族の事情 | 貼らない。要るなら「体調を理由に」程度にぼかす |
| 取引先との約束で守る情報 | 秘密保持契約（取引で知った情報を外に出さないと約束する契約）の対象の資料、見積もりの単価、取引条件 | 貼らない。数字は「約1割」のような比率に直す |
| 公表前の社内情報 | 発表前の決算・新商品・人事異動、会議の議事録、「社外秘」の印がある資料 | 貼らない。構成や言い回しの相談なら、中身を伏せた見本で頼む |
| ログイン情報とシステムの中身 | パスワード、APIキー（システムどうしをつなぐための秘密の文字列）、社内システムの設定やソースコード | 貼らない |
| 公開済みの情報と一般的な質問 | 自社サイトに載せた商品説明、公表済みのプレスリリース、Excelの関数や敬語の使い方の質問 | 貼ってよい。勤務先が個人のアカウントでの業務利用を禁じていれば、そちらに従う |

※編集部が作成した目安。どの情報を社外秘とするかは勤務先の規程が決め、規程があればそちらに従う。

法人向けのプランは、会社が契約し、入力を学習に使わない条件などを定めた有料のプラン。勤務先がこれを用意し、入力してよい情報の範囲も決めているなら、その範囲の中では資料を貼ってよい。範囲が決まっていない職場や、個人のアカウントしか使えない場合は、表の情報を貼らずに、名前や数字を伏せて書き換えてから頼む。

## 名前と数字を伏せれば、頼める作業は多い
下書きや要約は、相手との関係、頼む内容、目指す結論が分かれば作れる。社名や実際の金額は、できた文に後から自分で入れ直せばよい。

**例1（架空）：取引先への返信メール**

> 改善前：北山商事の田村部長から、11月納品分の単価を1個1,280円から1,150円に下げてほしいと言われた。うちの原価は1個980円。1,220円で落ち着かせたい。返信メールを書いて。

> 改善後：取引先の担当者から、来月納品分の単価を約1割下げてほしいと頼まれた。関係を保ちながら、値下げ幅を半分ほどにとどめたいと伝える返信メールの下書きを作って。丁寧な敬語で300字以内。

改善後の文は、社名と人名を消し、単価を比率に置き換えている。返信に要らない原価は書いていない。

**例2（架空）：会議メモの要約**

> 改善前：次の会議メモを要約して。（以下、会議メモの全文。「営業1課の佐藤さんは今期目標の6割で、持病の腰痛で9月に2週間休んだ。来期は鈴木さんと担当を入れ替える。」などを含む）

> 改善後：次の会議メモを、決まったこと・担当・期限の表にして。人の名前は担当者A、担当者Bに置き換えてある。（以下、メモから氏名、評価、休んだ理由を消したもの）

要約には、誰が何をいつまでにするかが分かれば足り、評価や体調の話は要らない。氏名を役割の記号に替え、健康の情報は消してから貼る。

**例3（架空）：顧客リストの集計**

> 改善前：（顧客リスト2,000行をそのまま貼って）都道府県ごとの件数を出す方法を教えて。

> 改善後：A列に会社名、B列に都道府県、C列に契約日が入った表がある。1行の例は「株式会社サンプル｜東京都｜2026/04/01」。都道府県ごとの件数を数えるExcelの関数を教えて。

関数や手順を教わるだけなら、実物のデータは要らない。列の並びと架空の1〜3行を示せば足り、できた関数を手元のファイルで使う。ファイルをまるごとアップロードするときも、要る列だけを残した写しにする。

## 学習に使わせない設定は、アカウントで違う
Gemini、Copilot、Claudeのどれも、勤務先が契約した仕事用のアカウントなら、入力をAIの学習に使わないと各社が明示している。個人のアカウントでは、GeminiとClaudeは設定で学習を止められる。個人向けCopilotの新しいアプリには、止める項目の説明がない。

| サービスとアカウント | 入力を学習に使うか | 止める方法と、止めても残る扱い |
|---|---|---|
| Gemini（個人のGoogleアカウント） | 「アクティビティの保存」がオンなら、会話の一部をGoogleの担当者が確認し、AIモデルの学習を含む改善に使う。18歳以上は初めからオン | 「アクティビティの保存」をオフにすると、フィードバックを送った会話を除き、以後の会話は学習に使わない。オフでも会話は最長72時間保存され、Googleの担当者が確認済みの会話は最長3年残る |
| Gemini・Gemini in Workspace（勤務先や学校が契約したGoogle Workspaceのアカウント。対象の契約プランに限り、当てはまるかは社内の管理者に確かめる） | Googleの担当者は確認せず、組織の許可なく学習にも使わない | 組織の契約とデータの保護が自動で適用される |
| Microsoft Copilot（個人のMicrosoftアカウント。2026年8月18日以降の新しいアプリ） | プライバシーに関する声明は、プロンプト（AIへの入力文）と関連データを、サービスの提供・改善と、関連する広告に使うと定める | 新しいアプリの設定の説明（メモリ、チャット履歴、広告など）に、学習を止める項目の記載がない。以前のアプリは学習を止める設定があった |
| Microsoft 365 Copilot・Copilot Chat（職場・学校のアカウント） | 入力と回答を、基になるAIモデルの学習に使わない | 職場・学校のアカウントで使えば、企業向けのデータ保護が自動で付く |
| Claude（Free・Pro・Maxの個人向けプラン） | 「Claudeの改善」への利用を許可した場合に学習に使う。許可すると、会話は学習用に最長5年保持されることがある。安全性の確認で問題があるとされた会話は、許可していなくても安全対策のモデルの学習に使うことがある | 「AIモデルの改善を支援する」をオフにすると、新しい会話は以後の学習に使わない。会話は自分で削除でき、削除すると原則30日以内にサーバーからも消える。シークレットチャットは設定にかかわらず改善に使わない |
| Claude for Work（Team・Enterprise）と、API（自社のシステムからClaudeを呼び出して使う契約） | 初めから学習に使わない | 評価ボタンなどでフィードバックを送った会話は、学習に使われることがある |

※出典：Google・Microsoft・Anthropicの公式ヘルプとプライバシーに関する説明（2026年10月11日閲覧。題とURLは記事末尾の【参照元】）。表は公式ヘルプに書かれた範囲の要約で、設定の名前や画面は変わることがある。

個人のアカウントで仕事の文章を扱うなら、使う前に学習を止める。

1. Geminiは、パソコンで「設定とヘルプ」から「アクティビティ」を開き、「アクティビティの保存」をオフにする（Gemini アプリ ヘルプ「Gemini アプリのアクティビティを管理、削除する」）。
2. Claudeは、名前のメニューから「設定」「プライバシー」と進み、「AIモデルの改善を支援する」をオフにする（Anthropicのプライバシーセンター「モデル改善のプライバシー設定を変更するにはどうすればよいですか？」）。
3. 個人のMicrosoftアカウントで使うCopilotは、新しいアプリの設定の説明に学習を止める項目がない。仕事の文章は貼らず、勤務先のアカウントで使えるCopilot Chatがあれば、そちらで頼む。
4. ChatGPTは、まず勤務先が法人向けの契約をしているかを確かめ、あればその契約のアカウントで使う。個人のアカウントしかないなら、入力が学習に使われるかと止める方法を公式ヘルプで確かめるまで、社外の人の情報と社外秘の資料は貼らない。
5. 1回だけ使う相談は、Geminiの一時チャットやClaudeのシークレットチャット（どちらも会話が履歴の一覧に残らない使い方）で始める。どちらも学習には使われない。
6. 回答の良し悪しを送る評価ボタンは、社外の情報が入った会話では押さない。Geminiは学習を止めていても、フィードバックとして送った内容を改善に使う。Claudeは評価した会話の全体を最長5年保存する。

学習を止めても、社外秘を貼ってよいことにはならない。Googleは、アクティビティの保存をオフにした会話や一時チャットも、72時間はアカウントに残す。その間に、利用者や社会を守る目的でGoogleの担当者が確認することがある。社員が個人のアカウントに入れた業務の情報は、勤務先が把握できないことがある。勤務先が持ち出しを禁じている資料は、設定にかかわらず個人のアカウントに貼らない。

## 勤務先のルールを確かめ、迷ったら貼らずに聞く
勤務先に生成AIの利用ルールがあれば、それに従う。ルールを作る側の経営者や担当者は、法人向けプランを契約する前に、入力を学習に使わないこと、会話の保存期間、管理者が利用状況を見られるかを確かめておく。ルールが見当たらない職場では、個人のアカウントに社外の人の情報と社外秘の資料は貼らず、使ってよいかを上司か情報システム部門に聞く。使う側は、貼る前に一度、使ってよいサービスと入力してよい情報の区分を読み、次の点を確かめる。

- 勤務先のルールで、使ってよいサービスとアカウントを確かめた
- 仕事用のアカウントでログインして使っている（個人用なら、学習を止める設定をした）
- 貼る文章から、氏名・連絡先・社員番号を消すか記号に置き換えた
- 取引先の名前、単価、取引条件を伏せるか比率に直した
- 健康や人事評価など、本人が知られたくない情報を消した
- 発表前の情報や「社外秘」の資料をそのまま貼っていない
- ファイルは要る部分だけの写しにした
- 社外の情報を含む会話で、評価ボタンやフィードバックを送っていない

どれか1つでも迷ったら、その資料は貼らずに、書き換えた見本で頼む。

さらに詳しく：生成AIの社内ルール作りを任されたけれど手本がない　参考にできる国の資料と、業界団体のひな形の違い（社内ルールに入れる項目と、国の資料と業界団体のひな形の使い分けが分かる）

## 学ぶなら、情報の扱いを演習で確かめる
生成AIの講座には、課題の練習に、受講者が自分で用意したAIのアカウントを使うものがあり、その場合も練習の前に学習を止める設定が要る。編集部は2026年10月4日時点で、AI講座21講座の公式サイト・利用規約を調べた。分野に生成AIの活用を含む12講座のうち4講座は、AIツールの有料プランや利用料を受講者の負担と明記していた。

| 受講中に使うAIツールの費用 | 生成AIの活用を学ぶ12講座での数 |
|---|---|
| 有料プランや利用料を受講者が負担すると明記 | 4講座 |
| 無料版のAIで学ぶと明記 | 1講座 |
| 公式サイト・規約で記載を確認できなかった | 7講座 |

※出典：編集部調べ（2026年10月4日時点）。AI講座21講座の公式サイト、利用規約、特定商取引法に基づく表記（会社名や連絡先、解約の条件を載せるページ）を確かめた。分野に生成AIの活用を含まない9講座（開発、データ分析、E資格が中心）は数に入れていない。

自分のアカウントで練習するなら、受講を始める前に学習を止める設定をし、課題に勤務先の資料を使うときは、名前や金額を伏せて書き換えてから貼る。情報の扱いを講座で学ぶなら、公式サイトのカリキュラムに、セキュリティや情報管理の単元があるかを見る。短い時間で基本と注意点を講師に教わりたい人には、通学もできる数回の講座が合う。たとえばWinスクールの生成AI講座は、90分×3回の中に「生成AIとセキュリティ」の単元がある（税込40,700円）。ただし、自分の仕事の課題を持ち込んだ個別指導はなく、職場の資料で相談したい人には向かない。人事など個人情報を扱う仕事で使うなら、職種別のコースで、一時チャットの使い方や個人情報を伏せる演習があるかを確かめる。職種別のコースがある月額制の講座には自動更新のものがあり、数週間だけ学びたい人は、受講期間の決まった講座と総額を比べる。
