# アイキャッチ画像の検索語（記事1）

記事: 国交省、建築物のライフサイクルカーボン評価で10月5日に検討会。大規模事務所の届出制度の2028年度開始へ算定ルールなどを議論

区分: **B（固有の施設に限らない話）**。制度の話で、特定のビル・現場を扱っていないので、建物や工事現場の写真でもよい。
選ぶ基準: Shutterstock の商用可のみ（`isEditorial` が false）。画像だけで「建物を建てる段階のCO2（資材・施工）」の話だと分かるもの。

※ このセッションからは Shutterstock に接続できない（サイトのボット対策で 403）。画像 ID の候補は、天野さんのブラウザか、手元の環境で選ぶ。

## 1組目（第一候補にしたい構図）
- 検索語: `office building construction site crane` / `high rise construction steel frame concrete`
- 読者が思い浮かべる話題: 大規模オフィスビルの建設。届出制度の最初の対象が大規模事務所で、資材の製造から施工までの排出が評価の対象になる
- 避けるもの: 社名・ロゴ・看板が読める現場、実在の有名ビルと分かる外観

## 2組目
- 検索語: `building materials concrete steel timber stack` / `construction materials rebar cement`
- 読者が思い浮かべる話題: 建材ごとのCO2（炭素排出量原単位）と、建材メーカーの表示
- 避けるもの: 特定メーカーの製品名・包装が写るもの

## 3組目
- 検索語: `architect blueprint laptop carbon footprint` / `engineer calculating building carbon emissions`
- 読者が思い浮かべる話題: 設計の段階でのライフサイクルカーボンの算定と、建築士から建築主への説明
- 避けるもの: 画面の数値やグラフが記事と違う内容に読めるもの、「CO2」の文字を大きく合成したイラスト（記事は写真だけで選んできた）

補足: 1組目を第一候補にする（題の「大規模事務所」「建築物」と直接対応する）。`eyecatch_alt` の例: 「建設中の高層ビルの鉄骨とクレーン」。
